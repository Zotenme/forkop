# Forkop

Forkop — сервис маршрутизации трафика для OpenWrt на базе sing-box с LuCI-интерфейсом.

Этот репозиторий — самостоятельно поддерживаемый форк [ushan0v/forkop](https://github.com/ushan0v/forkop) (бывший Podkop Plus), который, в свою очередь, является форком [Podkop](https://github.com/itdoginfo/podkop).

### Установка

```sh
sh <(wget -O - https://raw.githubusercontent.com/Zotenme/forkop/main/install.sh)
```

Forkop работает на [sing-box-extended](https://github.com/shtorm-7/sing-box-extended) 1.14 и новее. Установщик ставит его сам, а sing-box из пакетов OpenWrt заменяет на него.

### Возможности

* Поддержка подписок.
* Транспорт XHTTP.
* Цепочка DNS-серверов: каждый запрос идёт к серверам по порядку, пока один не даст нормальный ответ.
* Обновлённый LuCI-интерфейс.
* Расширенное управление секциями.
* Расширенные условия маршрутизации.
* Возможность поднять собственный VPN/proxy-сервер.
* Менеджер обновлений и установки компонентов.
* Встроенный мониторинг соединений.
* Расширенные настройки URLTest-групп.
* Автоматический выбор узла по приоритету.
* Каскадные подключения.
* Маршрутизация DNS-запросов через прокси.
* Резервные DNS-серверы.
* Отдельные DNS-серверы для выбранных доменов.
* Поддержка IPv6.
* Действие Bypass с полным обходом sing-box.
* Интеграция Zapret, Zapret2 и ByeDPI как отдельных действий секции.
* Служба полностью написана на ucode.
